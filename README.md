# Poker Range Trainer v5

GitHub Pages用の完成版です。

## v5変更点

- 2ステップ実戦を廃止
- ボード分類単独モードを廃止
- 間違い復習を廃止
- プリフロップ問題を70問に拡充
- ボード有利不利を5択化
  1. Dry / PFR有利
  2. Semi Dry / PFR有利
  3. Wet / ほぼ互角
  4. Low / Caller有利
  5. Paired / PFR有利
- 戦略表・SB戦略・オープンレンジを「レンジライブラリ」に統合
- ボード辞典・用語集を追加
- ランダム出題後に回答できない不具合を修正済み
- サメのキャラクターを追加
